# 团队头像来源

均为公开主页/机构页发布的照片。页面上的 `.webp` 是加工件，300×300，页面用 CSS 切成
圆形展示（直径 96~112px）。

加工规则是**保持原图、把圆形的裁切降到最低**：

1. 每张只取源图能给出的**最大内接正方形**（边长 = 短边），不放大、不推近，所以只
   切掉长边多出来的部分：切掉 0%（nakayama）到 29%（zhu-fei）。
2. 正方形的位置只在剩余余量里挪：横向往人脸对称轴靠（对称轴用左右镜像差最小的
   竖线自动定位），纵向把眼线放到 40% 高度。余量为零的方向就保持原构图。
3. 不做人脸大小归一化 —— 那需要把宽松的几张推近裁掉六七成。代价是各人脸在圆里
   占比不同（头占直径 29%~66%：liu-hongbin / liu-wenzhuo / zhu-fei 三张源图本身
   就是证件照式特写）。

liu-chenglin 是例外：源图里人本来就偏左，横向余量为零，只按规则 2 挪没法让脸居中。
所以正方形整体左移 417px（占边长 15.4%），左边空出来的部分复制源图最左一列像素补齐
——那一带是平滑的深蓝背景，补出来的部分落在圆内也看不出接缝。边长、缩放比例都没变，
只是把人挪到了圆心。

换照片时按下表来源重新下载原图，量出发顶/下巴/眼线/人脸中线四个值，再按上述规则
重新生成即可。
