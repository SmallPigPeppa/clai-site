持续学习Continual Learning

持续学习研究模型沿任务序列增量训练的问题：在仅能访问当前任务数据的约束下学习新任务，同时保持既有任务的性能，主要障碍是灾难性遗忘（catastrophic forgetting）。本站整理该方向的背景、问题设定与评测协议，维护统一口径的榜单，并开展 CLightning、CLAgent 与 CLOCR 研究项目。

01 · 背景

从单次训练到持续学习

标准监督学习假设数据分布固定、训练一次完成。实际部署中，数据分布与任务集合随时间变化；完整重新训练的代价随模型规模增长，历史数据也常受存储与隐私约束而无法长期保留。持续学习（continual learning，又称终身学习）研究模型沿任务序列增量训练、同时保持既有任务性能的问题。

研究脉络

问题在不同阶段呈现不同形态：需要保持的对象从分类边界，到零样本迁移能力、指令跟随与通用能力，再到智能体的经验与技能；评测与理论随之演进。

1989问题提出

灾难性干扰在连接主义网络上被系统刻画，稳定性—可塑性两难成为领域的基本框架。

McCloskey & Cohen · Grossberg
2016–2021深度网络时代

正则化（EWC / LwF）、回放（iCaRL）与结构扩展（DER）确立方法版图，研究集中于类别增量设定。

PNAS 2017 · CVPR 2017 / 2021
2021–2023预训练时代

冻结骨干加提示或低秩模块成为主流范式；CLIP 的零样本能力本身成为需要保持的对象。

L2P, CVPR 2022 · NMI 2022
2023–大模型时代

持续预训练、持续指令微调与持续对齐的多阶段框架成形；需要保持的对象扩展为指令跟随与通用能力。

Wu et al. 2024 · Shi et al. 2024
2025–智能体时代

研究对象延伸到沿任务流积累经验的智能体：持续学习从参数更新扩展到经验与技能的积累，见 CLAgent。

Silver & Sutton 2025

02 · 问题设定

任务序列上的增量学习

任务 t1 → t2 → … → tT 依次到来；训练第 i 个任务时仅能访问该任务的数据，历史数据至多保留有限缓存。依推理阶段是否提供任务身份、判别所在的标签空间以及数据分布的演化方式，问题划分为任务增量、数据增量、类别增量与域增量等设定（van de Ven, Tuytelaars & Tolias, Nat. Mach. Intell. 2022）；在预训练大模型上进一步延伸出持续指令微调等形态（Wu et al. 2024; Shi et al. 2024）。

03 · 关键挑战

灾难性遗忘与稳定性—可塑性两难

持续学习面临相互制约的困难：新任务的训练导致灾难性遗忘；抑制遗忘所施加的约束会损害新任务的学习乃至长期可塑性，即稳定性—可塑性两难；性能损失集中发生在任务切换前后，仅在任务末评测无法观测。

现象 灾难性遗忘

在新任务上继续训练会显著降低既有任务的性能：对既有任务重要的参数被新任务的更新覆写。（McCloskey & Cohen, 1989; Kirkpatrick et al., PNAS 2017）

✓ 96% 学习任务 t1 后 ✗ 31% 学习任务 t2 后
权衡 稳定性—可塑性两难

网络须足够可塑以学习新任务，又须足够稳定以保留既有知识；约束过强会抑制学习，长期甚至导致可塑性丧失。既有方法均在两端之间选取工作点。（Grossberg, 1980; Dohare et al., Nature 2024）

遗忘 僵化 完全可塑工作区完全稳定
现象 Stability gap

任务切换后，既有任务性能先骤降、再部分恢复；仅在任务末评测会高估稳健性，该暂态只有逐状态评测可以观测。（De Lange et al., ICLR 2023）

只在任务末评测94% 切换瞬间 · 仅逐状态可见62%

前两者界定方法设计的取舍空间——既有方法均在稳定性与可塑性之间选取工作点；第三者对评测协议提出要求：性能须在每个训练阶段之后度量，而非仅在序列末尾。下一节的指标即建立在这一要求之上。

05 · 我们的项目

开源研究项目

CLightning 是持续学习方法库套件，各子库分别面向类别增量、视觉语言模型的域增量微调与多模态大模型的持续指令微调；CLAgent 以持续学习为核心能力，研究经验积累、技能沉淀与自我改进的智能体系统；CLOCR 面向文字识别，研究版式、语种与年代分布漂移下的识别能力保持。

三者采用同一套实验约定：YAML 配置化定义 · 统一学习器基类 · 逐阶段状态导出 · EvalKit 共享指标

clightning · 安装与使用 
# 安装:conda 一步建环境(torch 2.8.0 · transformers · peft)
$ conda env create -f environment.yaml
$ conda activate torch-2.8.0

# 使用:单份 YAML 定义一次持续学习实验
$ python train.py config/demo.yaml
$ python eval.py config/demo.yaml --config config/eval/coin.yaml

outputs/demo/cl_summary.csv   # ACC / AIA / BWT / 遗忘度
# CLightning 整套封装为智能体可调用的技能(skill)
$ clagent skill add clightning
$ clagent run "在同一条指令任务序列上对比 olora 与 moelora"

  规划实验 → 调用技能训练与评测 → 汇总 CL 矩阵
  经验沉淀为新技能,积累而不覆写既有能力
# 研究对象:版式、语种与年代分布漂移下的识别能力保持
# 数据序列与识别器在同一份 YAML 里声明
$ python train.py config/ocr.yaml
$ python eval.py config/ocr.yaml --config config/eval/ocr.yaml

outputs/ocr/cl_summary.csv   # CER / WER + CL 矩阵
